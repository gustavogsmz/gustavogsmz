## About

Full Stack Software Developer focused on the **.NET ecosystem**, building and evolving production web applications with **C#, ASP.NET MVC/Core and PostgreSQL**. My background began in infrastructure and networking, giving me a practical view of corporate environments, support, deployment and the systems that keep businesses running.

Today I work across the application lifecycle: interfaces with Razor Views, JavaScript, Bootstrap and jQuery; business rules and integrations; data access with Entity Framework and Dapper; background processing with Workers; automated tests; and continuous improvements to performance, reliability and maintainability.

I also apply artificial intelligence to real software products, creating dashboard insights, report automations and virtual assistants. I approach engineering with a product mindset: understand the business problem, design a clear solution and deliver software that can evolve safely.
